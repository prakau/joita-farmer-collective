# Joita Farmer Collective 1.1.2

Download **JOITA-Farmer-Collective-1.1.2.apk** on an Android phone. Open the download and tap **Update** (or **Install** the first time). Do not uninstall an earlier version: updating preserves local farmer records.

## A–F farmer impact form

- Hindi field entry follows the supplied JOITA / CCF impact form, with pinned A–F section tabs and next/previous navigation.
- Tap-to-select single-choice and multi-select options cover the form's common response questions. Example chips speed crop, units and comparison-period entry; typed values remain editable.
- Project farmer ID, plot ID, assessed acreage and crop/stage are required so each impact report identifies the farmer's actual assessed plot.
- Forms auto-save as drafts on this phone. Baseline, follow-up, final and correction records are saved to the farmer's dated history.
- Actual soil readings, quantities, farmer responses and photo evidence must be recorded by field staff. Unknown answers can remain blank; the app does not invent measurements or calculate CO₂e.
- Camera/gallery photos and consent notes remain part of local evidence; consent is never selected by default.

**Quick start:** किसान जोड़ें → profile सहेजें → A–F प्रभाव आकलन भरें → सहेजें → किसान रिपोर्ट से PDF या प्रमाण ZIP export करें।

Records remain offline on this phone. Export a backup copy before changing phones. Acknowledgement is the officer's record, not an electronic signature. Confirm Climate Collective's evidence requirements; this app does not independently verify impact or certify carbon claims.

Android 6.0+. Signed with the existing JOITA release certificate; updates earlier Farmer Collective versions in place.
