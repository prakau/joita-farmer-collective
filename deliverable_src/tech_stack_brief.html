Joita-V2

The Tech Stack & Cost Optimization Brief

One-page architecture defense for audit-grade MRV across fragmented Indian farms while keeping platform spend under $10 / Rs 830 per farm.

Recommended Stack

Edge Layer

React Native keeps the product Android-first for low-end devices with direct GPS, camera, and background worker access.

WatermelonDB + SQLite is the required offline layer: it stores polygons, evidence manifests, and sync checkpoints on-device until a stable 4G window appears.

Core Backend

Supabase + PostgreSQL/PostGIS remains the source of truth for auth, storage, spatial records, and dashboard read models.

Node.js / Edge Functions handle idempotent ingestion, event projection, evidence validation, and payout-trigger workflows.

Spatial + ML

H3 indexing makes overlap detection and national heatmaps cheap even with millions of micro-landholdings.

Sentinel-2 + ISRO Bhuvan APIs provide low-cost satellite context for tree-growth review and field-edge anomaly checks.

Why WatermelonDB
  • Supabase is strong as a hosted backend, but it does not natively solve rural offline sync or replay-safe polygon uploads.
  • WatermelonDB acts as the edge database and keeps an append-only local event log in SQLite.
  • A background sync worker uploads only when connectivity, battery, and GPS quality are acceptable.
  • Each event carries an idempotency key, so retries cannot create duplicate polygons or duplicate biochar rows.
Cheap Accuracy
  • Use guided perimeter walks with multi-sample GPS averaging, corner pauses, and outlier rejection.
  • Store both the raw trace and simplified polygon so auditors can replay how a boundary was captured.
  • Run server-side QA against Sentinel-2 imagery and Bhuvan layers to flag implausible edges or area changes.
  • Use H3 overlap scans before approval to block double counting across adjacent or duplicated claims.
